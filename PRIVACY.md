# HatchLock Privacy Policy

_Last updated: 2026-11-09_

HatchLock is a set of instructions (skills) and, in Claude Code, local hook scripts.

- **Data collected:** none. HatchLock has no servers, accounts, analytics or telemetry.
- **Data transmitted:** none. The hook scripts run only tools already installed on your machine (compilers, type checkers, linters) against files in your project, and send nothing over the network.
- **Data stored:** HatchLock stores no personal data. In Claude Code, the TypeScript check may keep a compiler cache file (`hatchlock-*.tsbuildinfo`) in the plugin data directory or your system temp directory.
- **Third parties:** none. Your AI assistant provider's own privacy policy governs your conversations.

Questions: open an issue at https://github.com/tahmidbintaslim/claude-code-polyglot/issues
